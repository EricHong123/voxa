# Voiceleaf 黑白 macOS UI 提示词

为「声笺 Voiceleaf」设计并实现精致的 macOS 本地语音输入应用。仅使用黑、白和中性灰，不使用绿色、米色、彩色渐变或装饰性色块。遵循 Apple 系统应用的克制原则，保留真实 macOS 窗口控制与桌面侧栏，不移植手机底部导航。

## 整体语言

采用 SF Pro / 系统字体，中文使用 PingFang SC。主标题 30–34px，正文和主要控件 13–14px，辅助文字 11–12px；通过字号、字重、间距和表面层次建立信息层级。正文用近黑色，辅助文字保持可读的中性灰。画布使用极浅灰白，侧栏略深，主要操作使用黑底白字。

圆角按组件尺度控制在 8–20px。边框仅使用细微中性灰，阴影只用于选中的分段项、主要录音按钮和浮层。使用留白与对齐建立精致感，不堆叠多层描边、光晕、胶囊和卡片。动画仅服务于状态变化，150–220ms，支持 prefers-reduced-motion。

## 首页

视觉中心是录音操作，而不是宣传图。保留简洁标题与一行说明。听写／翻译／编辑使用原生感分段控件；录音区大面积留白，黑色圆形麦克风按钮为唯一强视觉焦点，单色声波、清晰状态文字和实体键帽提示构成辅助信息。模型就绪状态放在工具栏，隐私说明弱化。统计采用轻量横排；词典和表达风格以紧凑功能入口呈现。

## 历史

使用可扫描的时间与正文层级、轻分隔和低对比表面。搜索框、复制、删除、导出保持统一尺寸。空状态以单色图标和一句说明呈现，不添加虚构记录。

## 词典

新增词汇为主要操作，词汇以整洁网格或列表展示。删除按钮显而易见且拥有可访问名称。让数量和说明处于次要层级。

## 设置

采用 macOS 分组设置的节奏：组标题、控件行、说明文字。输入框、选择器、开关和模型连接状态统一为单色。设置保存和模型启动清晰可区分；技术路径可阅读，不截断功能。

## 悬浮条与图标

悬浮录音条使用近黑半透明材质、白色内容和简洁操作，轻微阴影。应用图标为圆角黑色底板与白色声波，延续主界面符号。

## 状态与可访问性

录音、处理中、错误、未连接不能仅靠颜色区分；必须同时提供文字和图标/形态。键盘焦点环使用清晰的灰黑边界。保留所有现有行为、权限提示、错误反馈和本地推理流程。不要把视觉改版变成业务重构。

## 验收

检查首页、空历史、词典、设置、录音悬浮条；在 1180×820 和 900×680 下无横向溢出。测试现有导航、词典增删、设置保存。生成桌面截图，检查真实渲染结果，打包新版应用。
