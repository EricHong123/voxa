## English launch

Title: Voxa: an open-source, local-first Typeless alternative for macOS

I'm building Voxa, a local voice dictation app with Whisper recognition, optional on-device text cleanup, and a small floating transcript panel. MIT licensed; no Voxa account or cloud API key required.

It's an early source-install alpha. Live draft replacement is experimental and app compatibility needs real-world testing. I'd especially welcome reproducible reports for plain text fields and contenteditable editors.

Repository: https://github.com/EricHong123/voxa

## Demo script to record after native verification

Use an empty disposable document. Show the actual model and hardware. Say a short sentence, correct one time or name, then pause. Show the real resulting text, not a staged animation. End with a visible limitation and a link to compatibility reports. Do not include private messages, API keys, or user history. Do not edit away processing delays without labeling the edit.
